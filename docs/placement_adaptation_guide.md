# SafeHalo 路由器摆放位置引导与算法自适应指南

在利用无线电（Wi-Fi CSI / 毫米波雷达）进行空间感知和防跌倒监测时，**“物理摆放位置”决定了 70% 的感知信噪比与准确率**。不同房间的物理特性（面积开阔度、床铺高度、淋浴水流、金属电器反射、宠物活动区）截然不同。

SafeHalo 引入了 **首次安装引导向导（Setup Wizard）与算法自适应引擎**（位于 [`src/safehalo/placement_adapter.py`](file:///Users/yifanwang/workspace/SafeHalo/src/safehalo/placement_adapter.py)），引导用户明确标记路由器与探针的摆放场景，系统将自动推导并下发物理级超参数，并自动触发 5 秒环境底噪基线校准。

## 2. 摆放高度的物理电磁补偿

路由器与探针的**垂直离地高度**决定了多径第一菲涅尔区（Fresnel Zone）的切割角度：

- **🪑 矮柜 / 低位安装 (0.3m ~ 0.8m)**:
  - 探针极度贴近地面，人体着地冲击和脚步反弹会被地面镜像路径放大 30%。
  - **算法补偿**：冲击阈值自动上浮 15%，避免因近距离拖地走步触发假冲击。
- **🖥️ 桌面 / 中位安装 (0.8m ~ 1.5m · 黄金推荐高度 ★)**:
  - 能量束精准位于人体胸腰高度，既能精准捕捉摔倒时人体重心骤降，又让地面 0.5m 以下的猫狗完全处于弱能量边缘。
  - **算法基准**：物理信噪比最高，作为标准基准。
- **💡 壁挂 / 吸顶高位安装 (1.8m ~ 2.5m)**:
  - 俯视角度，垂直下坠多普勒频移极其明显。
  - **算法补偿**：冲击阈值微调下浮 5%，并放大垂直速度分量权重。

## 3. 首次安装向导交互流程 (Web Setup Wizard)

当用户首次进入 SafeHalo Web 控制台（或未完成配置时）：
1. 页面将在 0.6 秒内**自动弹出**【🧭 路由器摆放位置与算法自适应向导】模态弹窗。
2. 用户依次选择：
   - **安装房间**（点击图标切换：客厅、卧室、卫生间、厨房、走廊）；
   - **安装高度**（低位、桌面中位、壁挂高位）；
   - **干扰选项**（勾选是否有猫狗宠物、是否有淋浴流水）；
3. 弹窗实时计算并展示：`⚡ 算法模型已自动推导最优超参数: 冲击阈值: 1.15 | 倒地静止确认: 3.0秒 | 卫生间极速防滑响应`。
4. 点击 **【🚀 确认保存并启动 5 秒环境底噪自校准】**。
5. 系统立即下发算法参数，并在终端/页面启动 5 秒全屋空房底噪学习，校准完毕后进入正式守护状态。

> **日常更换位置**：用户若将路由器搬动到其他房间，可随时点击顶部导航栏的 `📍 [房间名]` 徽标，重新唤起向导一键切换。

## 4. REST API 接口定义

### 4.1 查询当前摆放位置与适配参数
- **请求方式**: `GET /api/placement`
- **响应示例**:
```json
{
  "config": {
    "room_type": "BATHROOM",
    "room_name": "主卧卫生间",
    "mount_height": "MID_DESK",
    "room_area_sqm": 8.0,
    "has_pets": false,
    "has_water_splash": true,
    "is_configured": true,
    "updated_at": "2026-11-10 08:35:00"
  },
  "tuned_parameters": {
    "fall_spike_threshold": 1.15,
    "fall_stillness_seconds": 3.0,
    "pet_spr_threshold": 0.30,
    "radar_floor_height_thresh": 0.35,
    "hampel_window_size": 7,
    "water_flow_damping": true,
    "metal_multipath_damping": false,
    "description": "【卫生间极速防滑响应】: 跌倒冲击阈值调至 1.15，倒地静止 3 秒极速触发，启用花洒水流微动抑制"
  },
  "is_configured": true
}
```

### 4.2 保存摆放位置并触发即时适配
- **请求方式**: `POST /api/placement/save`
- **载荷格式**:
```json
{
  "room_type": "BEDROOM",
  "room_name": "老人主卧",
  "mount_height": "MID_DESK",
  "room_area_sqm": 18.0,
  "has_pets": true,
  "has_water_splash": false
}
```
- **响应示例**:
```json
{
  "success": true,
  "message": "摆放位置已设定为【老人主卧】，算法超参数已完成物理级调优，正在进行 5 秒自校准！"
}
```
