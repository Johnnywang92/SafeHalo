## 2. 射频节点物理摆放规范

CSI (信道状态信息) 对空间多径反射极其敏感。规范的物理摆放能显著抑制环境杂波，提高跌倒检测信噪比。

### 2.1 高度推荐：0.5 米 ~ 1.2 米 (桌面/床头中位)
* **推荐高度**: **0.8 米 ~ 1.0 米**（床头柜、茶几上方或离地 1 米墙壁托架）。
* **技术原理**:
  - 人体倒地后身体主要处于离地 0 ~ 0.3 米区间；站立或坐姿处于 0.5 ~ 1.7 米。
  - **切勿吊顶或过高安装（>1.8米）**: 垂直俯射多径会导致跌倒冲击沿垂向剧烈反射失真，且难以捕捉地表微弱胸腔呼吸。
  - **切勿贴地摆放（<0.2米）**: 地面地毯、拖鞋走动会造成过载近场杂散耦合。

### 2.2 角度与朝向原则
1. **优先对准跌倒极高危区域**:
   - **卧室场景**: 对准床沿上下床落脚处、床头通往房门主走道。
   - **卫生间场景**: 节点安装在卫生间门外干燥侧，对准淋浴区与马桶区（毫米波/CSI 无线电可良好穿透普通钢化玻璃门或木门）。
2. **避开大面积金属与电磁反射体**:
   - 节点正面前方 1 米内**严禁**紧贴大型冰箱、金属更衣柜、大面积穿衣全身镜。
   - 远离微波炉、电磁炉等同频 2.4GHz 强电磁干扰源。
3. **天线极化方向保持垂直**:
   - 胶棒天线必须垂直向上（或垂直向下），与家庭主路由器的偶极天线保持同极化状态，提升跨径接收信噪比 6~10 dB。

## 3. 路由器无线环境配置规范

SafeHalo 依靠连续稳定的 OFDM 子载波振幅/相位差分计算。路由器无线参数配置是系统稳定性的基石。

### 3.1 强制频宽锁定：20MHz (HT20)
* **必须配置为 20MHz 频宽**。
* **严禁开启 40MHz/80MHz 动态频宽**:
  - 动态频宽切换会导致 CSI 子载波数目在 52、108、234 之间跳变，直接破坏时域差分能量连续性。

### 3.2 固定 Clean 信道 (禁止自动跳频)
* **信道建议**: 固定使用 **Channel 1、Channel 6 或 Channel 11**。
* **现场勘测**:
  - 使用 Wi-Fi 信号扫描软件（如 WiFi Explorer 或手机开源 Wi-Fi Analyzer）扫描现场 2.4GHz 频段拥堵度。
  - 挑选信噪比最好、相邻 AP 干扰最小的信道固定写入路由器后台。
  - **必须关闭 Auto DFS / 智能自动跳频**。

### 3.3 信号基准底线
* 在部署位置，节点与主路由之间的 RSSI 应维持在 **-45 dBm ~ -68 dBm** 之间。
* 若 RSSI 弱于 **-72 dBm**，系统将触发弱信号告警，应调整路由器与采集节点相对距离或增配中继节点。

## 4. 上电初始化与 5 秒静默标定

SafeHalo 内置多径本底消除（Background Clutter Elimination）引擎，开机标定决定了后续特征提取的信噪比底色。

```
[上电启动] ---> [硬件自检] ---> [5秒全屋静默标定] ---> [基线就绪 (STANDING/EMPTY)]
```

### 4.1 静默标定执行步骤
1. 完成路由器与节点硬件通电，确保天线固定无松动晃动。
2. **通电后的 5 秒内，监测区域内必须保持无人（或受监护长辈在床上完全静止）**。
3. 严禁在此 5 秒内有人大步快走、宠物跑动或晃动室内家具。
4. 观察 Web 控制台首页或控制台输出：
   - 初始状态显示 `CALIBRATING`。
   - 5 秒后状态转变为 `EMPTY`（空房）或 `STATIC`（静态驻留），底噪能量趋于基准值（一般 base_variance < 0.005）。
   - 若检测到晃动，系统会提示默认抗噪基线，待环境平稳后自动重新自适应。

## 5. 人性化向导与通知通道闭环验证

现场技术人员通过笔记本/手机连接家庭局域网，打开浏览器访问：
`http://192.168.1.1:8091/` (以现场网关实际 IP 为准)

### 5.1 人性化配置向导 (Onboarding)
1. **守护对象称呼**: 输入例如“外婆”、“王叔叔”，生成温和有温度的日常通报。
2. **安装房间类型**:
   - **卫生间**: 算法自动切换至快速防滑模式（冲击阈值 1.15，倒地静止 3 秒快速警报，启用花洒水流抑制）。
   - **客厅**: 算法自动扩大时域滤波窗口，抑制窗帘被风吹拂抖动与多人经过杂波。
   - **卧室**: 优化睡眠深浅呼吸灵敏度，容忍正常翻身与起夜走动。
3. **日常作息习惯**:
   - 起居习惯（早起早睡 / 习惯起夜 / 日间小憩）。
   - 居住形态（独居老者 / 与家属同住）。

### 5.2 移动端通知通道绑定
SafeHalo 支持多通道冗余推送，现场必须至少绑定并打通一种高可靠通道：

1. **iOS Bark 关键警告强提醒 (强烈推荐家属是 iPhone 用户时使用)**:
   - 家属 App Store 下载安装 **Bark**。
   - 在向导或系统设置中输入家属专属 Bark Key。
   - **优势**: SafeHalo 的跌倒告警被标记为 `level: critical`，**可突破 iPhone 静音开关、睡眠专注模式及全局免打扰**，以最大音量发出警报！
2. **微信服务通知 (PushPlus 推送加)**:
   - 家属微信扫码关注【推送加】服务号，获取个人 Token。
   - 填入向导配置，支持多位家属微信群组同时接收通知（免装 App，全家弹窗）。
3. **Home Assistant 联动 Webhook**:
   - 填入 HA 自动化 Webhook URL。
   - 联动全屋智能家居：跌倒时玄关灯光变红、小爱音箱/HomePod 立即高音量语音播报。

## 6. 现场端到端测试与验收清单

现场交付给老人及家属前，必须按以下验收清单逐项打勾：

- [ ] **物理稳固度**: 节点使用无痕支架固定，无受风吹摆动隐患。
- [ ] **无线信道锁定**: 路由器已固定 20MHz 频宽，关闭自动跳频。
- [ ] **开机 5 秒标定**: 控制台显示底噪稳定，空房时状态稳定在 `EMPTY`。
- [ ] **防宠物干扰验证**: 若家中有猫狗，让宠物在地面活动 1 分钟，验证控制台识别为 `PetActivity` 且未误发跌倒警报。
- [ ] **本地安全质询应答**:
  - 技术员模拟快速坠落坐地动作。
  - 触发轻微蜂鸣质询声后，按下机身安全按钮或在 Web 端点击【我没事】，验证警报就地平稳解除。
- [ ] **端到端测试告警**:
  - 在控制台点击【发送测试告警】。
  - 确认家属手机收到微信推送 / Bark 强提醒，声音与文字内容正确无误。
- [ ] **初始密码修改闭环**:
  - 指导家属或现场管理员登录并完成初始密码 `admin123` 的强制修改，设置不少于 8 位的安全强密码。

## 7. 常见故障排障手册 (Troubleshooting)

### 7.1 误报问题排查 (False Positives)
* **现象**: 老人正常快速坐在沙发或床上时偶发跌倒预警。
* **排查与解决**:
  1. 打开 Web 控制台【事件记录】，点击该条记录选择【反馈误报】并勾选“正常坐卧”。
  2. 系统内置的自适应学习循环会自动将该房间冲击阈值阶梯上调 10%，静止确认时间延长 0.5 秒。
  3. 检查节点安装高度是否过高（>1.2米），高度过高会导致坐下瞬间体表垂直投影过大。

### 7.2 弱信号与子载波跳动 (Weak RSSI / High Jitter)
* **现象**: 控制台频繁提示 `RSSI weak (-74dBm)` 或时延抖动 > 15ms。
* **排查与解决**:
  1. 检查节点与路由器之间是否有承重墙、电冰箱或镜面阻隔。
  2. 检查节点天线是否松动，天线必须与路由器天线同向垂直立起。
  3. 将路由器 2.4GHz 发射功率由“节能模式”调整为“穿墙模式/高功率”。

### 7.3 射频节点断开与自动自愈 (ROUTER_OFFLINE)
* **现象**: 控制台进入 `ROUTER_OFFLINE` 状态。
* **排查与解决**:
  1. SafeHalo 具备串口心跳保活与自愈机制。
  2. 检查 Type-C 数据线是否松动或被踢碰。
  3. 重新插拔后，系统将在 2 秒内自动重新捕获 `/dev/ttyUSB*` 设备并自动恢复监测，无需重启网关。

## 8. 远程支持与合规脱敏日志导出规范

若现场遇到难以定位的疑难杂症需向研发团队提交技术工单，**必须遵从隐私合规原则，严禁外发包含明文家庭隐私、明文 MAC 与凭证的原始日志**。

### 8.1 一键脱敏导出指令
在路由器或边缘设备终端执行内置脱敏工具：

```bash
# 对全量运行日志与配置进行隐私假名化清洗
python3 scripts/sanitize_logs.py \
  --input-dir daemon-storage \
  --output-dir /tmp/safehalo_sanitized \
  --care-nickname "长辈姓名"

# 执行合规性自检 (如存在未脱敏明文将报警中断)
python3 scripts/sanitize_logs.py --check /tmp/safehalo_sanitized
```

### 8.2 脱敏内容保障
- 真实 BSSID / MAC 地址均转换为不可逆的一致性假名（如 `[MAC:a1b2c3d4]`），保证多链路分析能力的同时彻底隐匿实体路由器信息。
- 家属手机号、微信 Token、Bark 密钥、后台登录密码与 Salt 自动抹除。
- 随后将 `/tmp/safehalo_sanitized` 打包提供给研发技术支持。
