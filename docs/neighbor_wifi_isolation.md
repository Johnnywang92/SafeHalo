# SafeHalo 邻居 Wi-Fi 信号干扰隔离与空间排他算法指南

在居民住宅楼、多层公寓或合租房中，**邻居家的路由器及移动设备往往与自家的 Wi-Fi 工作在相同或相邻信道**。如果处理不当，隔壁邻居在家中走动、关门或掉落物品所引起的多径形变，会穿透分户墙被算法误判为自家老人的动作，从而造成**严重误报**。

SafeHalo 研发了 **5 层空间立体排他隔离算法**（位于 [`src/safehalo/neighbor_filter.py`](file:///Users/yifanwang/workspace/SafeHalo/src/safehalo/neighbor_filter.py)），从物理地址、信号空间损耗、多径频域吸收指纹到帧类型多维协同，彻底消除邻居信号串扰。

## 1. 邻居 Wi-Fi 干扰的五大来源与排他机制

```
                                      【空间无线电杂波源】
       ┌───────────────────────────────┬───────────────────────────────┐
       ▼                               ▼                               ▼
【隔壁邻居同频路由器】           【楼道过路行人手机】             【穿墙微弱多径散射】
TP-Link / 小米 / 华为等 AP       随机 MAC 广播 Probe 探针         穿透 24cm 混凝土承重墙
       │                               │                               │
       ▼                               ▼                               ▼
【第 1 层: BSSID 白名单】        【第 2 层: 随机 MAC 抑制】       【第 3/4 层: RSSI 与频域吸收】
仅放行自家路由器/Mesh MAC        过滤 Locally Administered MAC    门限截止 (-72dBm) + 混凝土斜率
       │                               │                               │
       └───────────────────────────────┼───────────────────────────────┘
                                       ▼
                       ┌───────────────────────────────┐
                       │ 纯净自居室内 CSI 多径特征流   │ ➔ 送入跌倒与作息状态机
                       └───────────────────────────────┘
```

| 防护层级 | 算法核心原理 | 防护目标与判决规则 |
| :--- | :--- | :--- |
| **第 1 层：BSSID 严格白名单硬隔离** | 物理源地址校验 | 仅允许自家主路由及 Mesh 子节点 MAC（如 `c0:06:c3:11:22:33`）的报文进入特征提取器。邻居所有非家网报文在入口处以 $O(1)$ 复杂度秒级丢弃。 |
| **第 2 层：家网冷启动自适应锁定** | 统计信噪比能量质心 | 若用户未手动输入 MAC，算法在前 50 个报文中自动对信道内所有 MAC 进行频次与均值 RSSI 复合评分，自动绑定家中信号最强的主路由，免去小白用户查找 MAC 难题。 |
| **第 3 层：空间 RSSI 边界包络过滤** | 建筑结构分户墙衰减模型 | 居民楼钢筋混凝土承重墙（厚度 18~24cm）对 2.4G/5G 衰减达 $18 \sim 30\text{dB}$。邻居穿墙信号通常弱于 $-75\text{dBm}$，SafeHalo 设立动态门限（默认 $-72\text{dBm}$），拦截一切隔墙弱信号。 |
| **第 4 层：混凝土实体墙频域吸收指纹** | 子载波频响倾斜 (Spectral Tilt) | 实体水泥墙对高频子载波的电磁吸收损耗显著大于中低频。计算子载波能量比率 $\text{Tilt} = \sum_{\text{高频}} |H_k|^2 / \sum_{\text{低频}} |H_k|^2$。若 $\text{Tilt} < 0.45$，判定为跨墙折射波予以剔除。 |
| **第 5 层：移动随机 MAC 探针清洗** | IEEE 802.11 临时地址位探测 | 楼道过路行人手机常发送随机 MAC 广播。通过检查 MAC 第一个字节的次低位（U/L 位），自动识别并丢弃随机临时探针。 |

## 2. 核心算法实现细节

### 2.1 随机 MAC 识别算法（纯位运算）
现代 iOS / Android 手机扫描 Wi-Fi 时均开启随机 MAC 防追踪。其物理 MAC 地址遵循 IEEE 规范：
```python
@staticmethod
def is_random_mac(mac: str) -> bool:
    """检查第一个字节的 U/L (Universal/Local) bit 是否为 1"""
    first_byte = int(mac[:2], 16)
    return bool(first_byte & 0x02)
```

### 2.2 承重墙频域高频吸收指纹 (Through-Wall Tilt)
自由空间直射或室内轻体墙反射，高频与低频子载波幅度比值平缓（$0.75 \sim 1.35$）。
当电磁波穿透厚度超过 15cm 的水泥承重墙时，高频发生剧烈介质吸收：
$$\text{Spectral Tilt} = \frac{\sum_{k=N/2}^{N-1} |A_k|^2}{\sum_{k=0}^{N/2-1} |A_k|^2}$$
当 $\text{Tilt} < 0.45$ 且信号处于临界弱场时，判定为隔壁邻居误入信号并直接拦截。

## 3. 使用与配置方式

### 3.1 明确指定自家路由器 MAC（最推荐，最纯净）
```bash
# 启动时指定自家路由器 BSSID (背面贴纸或管理后台可见)
python3 safehalo_service.py --router-mac c0:06:c3:11:22:33
```

### 3.2 零配置：全自动学习锁定家网
```bash
# 不传 --router-mac 参数，系统启动前 3 秒自动分析信道，锁定自居室内信号最强的路由器
python3 safehalo_service.py
```
终端与日志将打印：
```
[INFO] [NeighborFilter] 家网自动绑定成功！锁定主路由 MAC: c0:06:c3:11:22:33 (平均信号: -46.2 dBm)
```

## 4. Web 控制台与邻区干扰诊断

在 SafeHalo Web 仪表盘上（[`src/safehalo/web/index.html`](file:///Users/yifanwang/workspace/SafeHalo/src/safehalo/web/index.html)）提供实时**邻居 Wi-Fi 隔离指标卡**：
- **信道纯净度**：实时显示自家合法报文占比（如 `98.6%`）。
- **已拦截邻居包累计计数**：展示已隔离的邻居同频报文总量。
- **邻区 AP 发现数**：统计当前信道内发现的邻居 AP 节点数量。
- **信道切换避让建议**：若邻居同频竞争过大（纯净度低于 70%），系统自动提示建议将路由器信道手动锁定至互斥的 1、6 或 11 干净信道，或切换至 5G 频段。

API 接口：`GET /api/neighbor_spectrum` 输出完整的邻区干扰态势 JSON。
