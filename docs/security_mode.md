# SafeHalo Wi-Fi CSI 隐形防盗与安防模式指南

## 1. 为什么 Wi-Fi CSI 是天生的防盗雷达？

相比传统安防硬件（红外传感器 PIR、家用摄像头），Wi-Fi CSI 在防盗场景具备压倒性优势：

```
传统摄像头方案                     SafeHalo Wi-Fi CSI 方案
  [有死角、暗光失效、侵犯隐私]             [穿透墙壁、暗光工作、绝对隐私安全]
           │                                      │
  • 无法安装在卧室/卫生间                • 全屋无死角隐形布防，不侵犯隐私
  • 小偷戴帽子/拉电闸即失效              • 断电后 UPS 供电路由继续穿墙感知
  • 极易被猫狗误报                      • 独家算法已免疫地面宠物
```

1. **暗光与全黑环境可用**：无线射频波长（2.4GHz 约 12.5cm）不依赖任何可见光，夜间关灯拉窗帘不影响感知。
2. **隔门隔墙感知**：哪怕小偷躲在衣柜后、玄关转角或帘子后面，只要人体引起多径波形微变，即刻被捕获。
3. **零隐私顾虑**：不输出任何图像，完全适合布防在卧室、更衣室等私密区域。
4. **真正的硬件“一机两用”**：
   - **老人居家时**：系统为「跌倒与生理安全卫士」。
   - **离家外出 / 独居夜间时**：一键切换为「全屋隐形入侵防盗雷达」。

## 2. 三大安防布防模式

| 模式 | 适用场景 | 判决逻辑 | 告警形式 |
|---|---|---|---|
| **离家布防 (Away)** | 全家出门上班/旅行，家中本应无人 | 只要检测到 **HUMAN_MOVING** 或长时 **HUMAN_STATIC** 即刻告警（自动放行 PET 宠物） | 微信服务号最高优先级推送 + 外部声光警报 |
| **夜间布防 (Night)** | 家人夜间入睡后 | 仅对客厅、玄关、厨房节点布防；卧室仅运行跌倒监测 | 手机轻柔通知或联动夜灯，防贼入室 |
| **老人防走失 (Curfew)** | 患有阿尔茨海默病的老人看护 | 半夜大门节点检测到人体走动开门超过 5 分钟未返回 | 微信通知家属：“老人深夜离家外出” |

## 3. 防盗工作流程

```
 路由器 CSI 信号流
        │
        ▼
 [SafeHalo 状态机] ─── 检测到: 人体走动 (HUMAN_MOVING)
        │
        ▼
 [SecurityGuardEngine] ── 当前处于: ARMED_AWAY (离家布防)
        │
        ├── 检查宠物滤波器: 确认非地面猫狗 (Pet = False)
        ├── 检查出门缓冲期: 已超过 15 秒出门宽限期
        └── 触发入侵确认
                │
                ▼
      [AlertNotifier]
        ├── 1. 手机微信即时弹窗: 🚨【防盗告警】检测到非法人员入侵！
        ├── 2. 发送企业微信/钉钉家庭群 Webhook
        └── 3. (可选) 路由器联动蜂鸣器发出高分贝警报驱离
```

## 4. 软件使用与体验

在主程序启动时开启安防布防：
```bash
# 开启离家防盗模式，并配置微信报警
python3 router_detector.py --demo --pushplus-token YOUR_TOKEN
```
离家布防模式下，猫狗在地面活动时系统显示 `🐾 PET_ACTIVITY`，不会打扰您；一旦有人类走入房间，手机微信将在 2 秒内收到警报！
