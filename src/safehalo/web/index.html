📐 路由器与接收探针的“黄金摆放法则”

Wi-Fi 跌倒检测的精度 70% 取决于摆放位置。无线电在发射端（路由器）与接收端（ESP32-S3）之间会形成橄榄球状的第一菲涅尔区 (Fresnel Zone)，目标是让人体活动穿过该区域的主能量束。

[旧路由器 (AP)] [ESP32-S3 接收节点] (高 1.2m~1.4m) (高 1.2m~1.4m) \ ~~~~~~~~~~~~~~~~~~~~~~~~~~~~ / \ ~ 第一菲涅尔主能量束 ~ / \ ~ (人体胸腰高度，覆盖大部分动作) ~ / ==================== \~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~~/ ==================== 地面 (0~0.5m) [ 🐾 地面宠物跑动仅擦碰外边缘，被算法完全过滤 ]

1. 高度要求：1.2米 ～ 1.5米（最关键）

  • 正确做法：将路由器和 ESP32 放置在桌面、书架、床头柜或中位墙插上（与成年人胸腹高度齐平）。
  • 为什么：高位部署不仅能捕捉人体重心骤降（摔倒），更让地面上 0.5 米以下的猫狗活动只处于能量束死角，物理隔绝宠物误报。

2. 典型房间布局推荐

监测场景 路由器与探针建议位置 核心防范目标
老人主卧 路由器放床头柜，ESP32 放置在对面电视柜或房门对角线（直线距离 3~5米） 下床跌倒、床边滑落、起夜步态异常
高危卫生间 ESP32 安装在马桶正前方墙壁（1.3米防水盒），路由器置于卫生间门外 洗澡滑倒、如厕起身后眩晕倒地（Wi-Fi穿透木门/玻璃门）
客厅大开间 两端对角线放置，视距尽量跨越主要走道 行走摔倒、离家防盗全屋无死角覆盖

3. 严禁放置的“干扰黑名单”

  • 避开大型金属体与镜子：不要紧挨双开门大冰箱、大型落地全身镜（金属和水银镀层会全反射电磁波）。
  • 避开鱼缸与水体：2.4GHz 无线电极易被水分子强烈吸收。
  • 避开运转中的微波炉：微波炉工作在 2.45GHz，会造成信道噪声瞬时冲顶。

📡 什么样的旧路由器可以使用？

SafeHalo 支持两种硬件组网形式，兼容市面上几乎所有旧路由器：

接入形态 适用旧路由器 硬件成本 特点
形态 A：标准推荐（路由器 + ESP32 探针） 任何品牌的旧路由器
(如小米、华为、TP-Link、水星、腾达、华硕、网件等，只要有 2.4GHz)		 约 35 元 (1 块 ESP32-S3) 零门槛，无需拆机刷固件。路由器只需固定 2.4GHz 信道 20MHz，ESP32-S3 负责精准测 CSI。
形态 B：纯路由器自采自算（极客进阶） Qualcomm Atheros 芯片路由器
(可刷 OpenWrt 并打 Atheros CSI 补丁)		 0 元 利用路由器自身 Wi-Fi 芯片提取 CSI，难度极高，需要刷写改动内核的 OpenWrt。

形态 B 完美支持的经典旧路由器型号库

  • TP-Link: TL-WDR4300, TL-WDR3600, TL-WR703N, TL-WR841N v8/v9, TL-WDR7500 v2
  • D-Link: DIR-825 B1, DIR-505
  • 水星 / 迅捷: MW4530R (AR9344)
  • 网件 Netgear: WNDR3700 v4, WNDR3800

路由器后台关键 Wi-Fi 设置（必做）

  • Wi-Fi 频段: 仅开启 2.4GHz（5GHz 穿透差且多径波长过小）。
  • 固定信道: 务必从“自动跳频”改为固定信道 1、6 或 11。
  • 固定频宽: 设置为 20MHz (HT20)，禁止 40MHz 频宽捆绑。

🌐 怎样在公司或外出时，通过手机 4G/5G 远程访问 SafeHalo？

        
SafeHalo Web 控制台天然绑定 0.0.0.0:8080。由于家庭宽带通常无固定公网 IPv4，推荐以下三种零成本、高安全的远程访问方案：


        

          

            

              ★ 推荐方案 A：Cloudflare Tunnel
              免公网IP · 自动HTTPS
            

            

              无需在路由器上做任何端口映射，全球 CDN 节点穿透，且自动配置免费 SSL 绿锁证书，手机端打开最流畅安全。
            

            

# 1. 安装 Cloudflared
# macOS: brew install cloudflared
# OpenWrt: opkg update && opkg install cloudflared

# 2. 一键启动免费快速隧道:
cloudflared tunnel --url http://localhost:8080
            

            

              运行后终端将返回独立公网链接 (如 https://xxxx.trycloudflare.com)，直接发给家人即可远程使用。
            

          


          

            

              方案 B：Tailscale 虚拟专网
              点对点加密 · 极度安全
            

            

              在手机与路由器上同时安装 Tailscale，二者通过底层 WireGuard 协议组成私密加密内网。
            

            

# 手机与家庭路由器登录同一账号
# 手机浏览器直接打开 Tailscale 内网地址:
http://100.x.x.x:8080
            

            

              不经过第三方中继，完全对外隐身，杜绝黑客扫描。
